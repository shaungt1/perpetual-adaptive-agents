# Planning prompt used for this test case

This is what the owner types (after `/pa-plan`) to start the planning session for the test project. The vision paragraph below is stored verbatim by `pa vision add`.

---

/pa-plan tests/e2e/test-case/sample-project

My vision: notes-lite should be the simplest possible notes tool. I want to add a note, list my notes, and delete one, from the command line, and the notes must survive a restart. Keep it tiny and well tested, and write a short guide so anyone can use it in two minutes. Later I might want a web page for it, but not now.

Expectations: four agents at most, two tasks each to start. Spend no more than five dollars a day. Agents may merge small proven changes to the working branch; anything else comes to me.
