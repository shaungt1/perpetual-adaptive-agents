# Documents

This folder holds the project's own documents. They are listed in the order a newcomer should read them, and each one stands on its own.

| Document | What it is |
|---|---|
| `owner-vision.md` | The owner's description of the system, kept verbatim |
| `requirements.md` | The hard requirements (HR-01 to HR-82), mutable, with identifiers |
| `design-paper.md` | How the system works and why, mechanism by mechanism |
| `gap-analysis.md` | The starting point compared with the requirements, then the finished build compared with the same requirements, with evidence |
| `roadmap.md` | The remaining work, ordered by dependency, each stage with its completion test |
| `research/research-notes.md` | What was researched (assistant command lines, NATS, SQLite, decision models, prompt methods) and how sure each finding is |
| `research/prior/` | Earlier documents carried over for reference: the first design paper and the launcher guide. Some of their details have been superseded by `design-paper.md`. |
| `origins/` | The original vision and requirement documents from the first repository, kept verbatim |
