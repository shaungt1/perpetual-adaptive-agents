# Department playbooks

One playbook per kind of department. Read the one that matches your department before your first task. If yours is not here, use the closest one and the rules in `rules/`.

| Playbook | For |
|---|---|
| [frontend](frontend/SKILL.md) | Front end: User interface code: components, pages, styles, client-side state, accessibility, client performance. |
| [backend](backend/SKILL.md) | Back end: Server logic: services, business rules, background jobs, persistence and data access. |
| [api](api/SKILL.md) | APIs: Endpoints and contracts: routes, request and response shapes, validation, versioning, API documentation. |
| [ai-ml](ai-ml/SKILL.md) | AI and models: Model calls, prompts, evaluation, retrieval, and the data models need. |
| [data](data/SKILL.md) | Data: Schemas, migrations, pipelines, analytics and data quality. |
| [devops](devops/SKILL.md) | DevOps: Build, continuous integration, environments, deployment and infrastructure. |
| [testing](testing/SKILL.md) | Testing: Test suites, test tooling, coverage and end-to-end checks. Other departments still test their own work; this department strengthens the safety net. |
| [security](security/SKILL.md) | Security: Authentication, authorization, secrets handling, input safety and dependency health. |
| [docs-writing](docs-writing/SKILL.md) | Documentation and writing: Guides, references, READMEs, and long-form writing (articles, chapters, reports). |
| [research](research/SKILL.md) | Research: Investigating options, measuring, testing with users, gathering data over time, and recommending. |
| [content](content/SKILL.md) | Content and publishing: Articles, posts, newsletters, video scripts, and publishing to channels. Usually one agent per channel. |
| [design](design/SKILL.md) | Design and user experience: Visual design, interaction design, design systems and usability. |
| [finance](finance/SKILL.md) | Finance and analysis: Spreadsheets, financial models, recurring reports and analysis. |
